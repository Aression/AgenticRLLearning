## 论文要解决的问题

多轮 LLM Agent 训练的主流做法是 RLVR：每条轨迹只给一个结果奖励，中间决策缺乏监督。已有共识是，在线策略蒸馏（OPD）可以用教师给出的 token 级稠密信号补上这一稀疏性；在 Agent 场景中，教师常是同一模型在训练期才可见的特权上下文（如检索到的任务技能）下条件化得到的版本，学生则要在推理时无此上下文地复现教师行为，从而把技能内化进参数。

作者主张这一范式依赖两个未经检验的假设：其一，看到特权上下文的教师一定比学生强；其二，对齐教师在整个训练过程中始终有益。论文称在 ALFWorld 与 WebShop 上两者都不成立——共享参数的技能条件分支并不稳定优于它所监督的学生，且教师-学生差异先缩小后扩大，暗示奖励优化与行为对齐的梯度开始冲突。因此教师监督只是临时脚手架，关键问题是何时撤除。作者指出，已有工作用训练前固定的退火或两阶段切换计划，不观察教师是否仍有用。

## 方法

RetireOPD 分三阶段。第一，教师构建：把教师从学生解耦，在技能上下文下用环境奖励单独训练，使其先学会利用特权信息，而非仅靠提示。第二，联合训练：学生在自己采样的轨迹上同时接受 GRPO 的奖励信号与 OPD 的教师监督。第三，自适应退场：按固定间隔监控两个信号——教师-学生差异是否停止下降、学生成功率是否达到教师成功率的设定比例；两者同时满足即撤除 OPD，之后仅用 GRPO 继续训练，也不再需要教师前向计算。

作者给出一个一阶分析（附录 A）作为直觉解释：差异停滞意味着两个目标在局部梯度上相互对立。这一解释属于作者的理论论证，摘录中未给出完整推导。

## 证据与实验

论文报告在 Qwen2.5-1.5B、3B、7B 三个规模、ALFWorld 与 WebShop 两个环境上，RetireOPD 优于纯 RL、纯蒸馏与混合基线，相对 GRPO 在 ALFWorld 成功率提升 14.1%–18.8%、WebShop 准确率提升 11.8%–19.0%，并在所有设置下超过其自身的技能条件教师。训练动态部分称，从退场检查点继续联合优化会进入平台期，继续 OPD 甚至可能退化，而仅用 GRPO 可把成功率从 76.6% 提升到 93.8%。

需要强调：以上均为论文自报结果，本卡片未做复现，也未核验基线配置与统计显著性。摘要级数字不应视为已确证结论。

## 边界与未解问题

退场判据含两个超参数（差异停滞的判定方式、学生达到教师成功率的比例），摘录未说明其敏感性分析。差异停止下降的步数在不同模型与任务间从第 50 步到第 90 步不等（附录 E），这既支撑了在线判断的必要性，也意味着判据本身需要稳健。教师与学生同容量、共享或解耦的具体实现细节、以及教师训练成本是否被计入总开销，摘录中信息不足。方法仅在两个文本环境与三个模型规模上验证，能否推广到更开放的工具使用或长程任务尚不清楚。

## 与知识库的关系

本方法建立在 GRPO 与多轮 RL 之上，可视为对多轮 RL 稀疏奖励问题的补充路径：用特权上下文蒸馏提供稠密信号，再在适当时机回归纯奖励优化。它与奖励设计、多轮训练流程的笔记直接相关，也提示在训练系统中需要监控教师-学生差异这类额外指标。
